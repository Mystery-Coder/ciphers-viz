# Ciphers Viz

Interactive visualizations for classical cryptography algorithms. This project focuses on showing each cipher step-by-step so encryption and decryption logic is easy to follow.

## Live Demo

Check out the site, [Ciphers Visualized](https://mystery-coder.github.io/ciphers-viz/)

## What This Project Covers

- Additive (Caesar) cipher
- Multiplicative cipher
- Affine cipher
- Vigenere cipher
- Autokey cipher
- Hill cipher

## Core Features

- Real-time transform views for plaintext, key, and ciphertext
- Step tables for algorithm walkthroughs
- Visual components for mappings, matrices, and key streams
- Modular cipher implementations in TypeScript
- Reusable React components for consistent interaction patterns

## Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS

## Project Structure

- `src/ciphers` contains cipher logic and shared utilities
- `src/components/ciphers` contains interactive cipher panels
- `src/components/visualizations` contains reusable visual primitives
- `src/hooks` contains animation and UI behavior hooks

## Purpose

The goal is to make classical ciphers understandable at a glance, with visuals that connect the math to each transformation step.
